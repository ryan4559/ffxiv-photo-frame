# 光之相紙

為《FINAL FANTASY XIV》截圖加入白色攝影資訊底框，在瀏覽器中預覽並下載 PNG。

[開啟網站](https://ryan4559.github.io/ffxiv-ss-frame/) · 也可下載專案後直接開啟 `index.html`

## 使用方式

選擇或拖曳 PNG、JPG／JPEG、WebP 圖片，填寫拍攝參數與自訂文字即可。快門與 ISO 可留空；各參數都有獨立的「使用預設」按鈕。自訂文字可調整大小。

日期會優先讀取圖片資訊，讀不到時改用檔案最後修改時間，也可以手動填寫。圖片只在瀏覽器中處理，不會上傳。
